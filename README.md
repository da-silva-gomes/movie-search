# movie-search

Project is a tech challenge developed for an interview, utilizing the TMDB API to fetch and display movie data. The application is built using Vue 3, styled with TailwindCSS, and managed with Vite.

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
